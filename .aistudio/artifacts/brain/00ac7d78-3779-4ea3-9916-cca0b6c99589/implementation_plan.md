# Встроенная библиотека упражнений FORM Core

## Выполненные задачи

1. **Полноценная база данных (181 упражнение)**:
   - Включены все упражнения из предоставленного списка по 13 мышечным категориям: грудь (1–21), спина (22–44), плечи (45–59), бицепс (60–72), трицепс (73–84), предплечья и хват (85–94), пресс и кор (95–114), квадрицепсы (115–129), бицепс бедра (130–138), ягодицы (139–151), икры и голень (152–159), трапеции и шея (160–166), функциональный тренинг и бокс (167–181).
   - Все карточки реальные, без фиктивных данных, дубликатов и пропусков.

2. **Структура каждого упражнения**:
   - Уникальный идентификатор `id`;
   - Русское название (`name`);
   - Английское название (`nameEn`);
   - Основная мышечная группа (`primaryMuscle`) и категория (`categoryKey`, `categoryNameRu`);
   - Подкатегория / целевой фокус (`subCategory`);
   - Дополнительные мышцы (`secondaryMuscles`);
   - Тип инвентаря (`equipmentNameRu`, `requiredEquipment`);
   - Место выполнения (`location`: дом, зал, оба);
   - Тип упражнения (`type`: силовое, функциональное, изоляционное, с собственным весом, базовое);
   - Сложность (`difficulty`), дефолтные подходы, повторы, отдых;
   - Техника выполнения (`technique`) и варианты замены (`alternatives`).

3. **Интерфейс поиска и фильтрации**:
   - Поиск по названию на русском и английском языках;
   - Быстрые вкладки 13 мышечных групп + динамические чипы подкатегорий;
   - Переключатель локации (Все места / Дом / Зал);
   - Выдвижная панель фильтрации по инвентарю и типу движения;
   - Избранное с быстрой отметкой и счётчиком.

4. **Пользовательские упражнения**:
   - Возможность создания своих упражнений («+ Своё упражнение») с сохранением в `localStorage`;
   - Редактирование и удаление собственных упражнений;
   - Отображение бейджа «Своё».

5. **Интеграция**:
   - Вкладка «Тренировки» → подраздел «Библиотека»;
   - Конструктор программ (добавление и замена);
   - Селектор добавления упражнений в активной тренировке и при редактировании завершённых сессий.
